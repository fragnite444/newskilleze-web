Quick Answer

This course teaches the basics of how websites are built and put online. You learn HTML, CSS, JavaScript, React, Node.js with Express, and a SQL database called PostgreSQL. It suits students and working people with no coding background, and you finish with three live projects and a portfolio page to show employers or clients.

Week-by-Week Syllabus — Web Development

9 modules · 5 months (20 weeks · 160 hours of instruction)

Module 1How the Web Works and HTML

Weeks 1-2
  • What happens when you type a website address: browser, server and domain name in simple words
  • Setting up the laptop with VS Code and the browser's developer tools
  • HTML tags for headings, paragraphs, links, images and lists
  • Tables, forms and buttons, with a contact form for a clinic
  • Writing clean, well-organised pages that search engines and screen readers can read
  • Adding video, maps and a WhatsApp chat link
  • Building a one-page website for a local shop
HTML5VS CodeChrome DevTools

Outcome: Write a complete HTML page by hand and explain what each part does.

Module 2CSS and Responsive Design

Weeks 3-5
  • How CSS styles a page: colours, fonts, spacing, borders and shadows
  • The box model, which decides how much space every item takes
  • Flexbox for laying out menus, cards and rows
  • Grid for full page layouts like a product page or a gallery
  • Responsive design: one page that looks right on a phone, tablet and laptop
  • Media queries, CSS variables and simple hover effects
  • Turning a Figma design for a clothes shop into a real page
CSS3Flexbox and GridFigma (view only)Chrome DevTools

Outcome: Build a good-looking page that works on mobile screens, using Flexbox and Grid without copying ready-made templates.

Module 3Git, GitHub and Your First Live Site

Week 6
  • Git in simple words: saving versions of your work, so mistakes can be undone
  • Commit, branch, push and pull using the terminal
  • Creating a GitHub account and a repository for each project
  • Writing a short README that explains your project
  • Putting a static site online with GitHub Pages or Netlify
  • Buying a domain name: what it is and what to check before you pay
GitGitHubGitHub PagesNetlify

Outcome: Save your work on GitHub and put a simple site online with a link you can send to anyone.

Module 4JavaScript Fundamentals

Weeks 7-9
  • What JavaScript does on a page: making things react to the user
  • Variables, numbers, text, true/false values and operators, with a GST bill calculator
  • If and else, loops and switch to make decisions
  • Functions, including arrow functions, with small daily-life exercises
  • Arrays and objects: holding a list of products or students in code
  • Array methods like map, filter and find, explained with a shop's product list
  • Modern JavaScript: let and const, template strings, destructuring and modules
JavaScript (ES2024)VS CodeNode.jsBrowser console

Outcome: Solve small problems with JavaScript, such as bill totals, marks lists and product filters, and read other people's code.

Module 5The DOM, Events and Working with APIs

Weeks 10-11
  • The DOM: how JavaScript reads and changes the elements on a page
  • Click, type and submit events, with form checks before sending
  • Building a to-do list and a simple quiz that react to the user
  • What an API is: a way to ask a server for data, like a waiter taking an order to the kitchen
  • Using fetch to get live data, with loading and error messages
  • Async and await, explained with the idea of waiting for a food delivery
  • Saving small data in the browser with localStorage
JavaScriptFetch APIPostmanlocalStorage

Outcome: Build a page that takes input, talks to an online API and updates itself without reloading.

Module 6React for Modern Front Ends

Weeks 12-14
  • Why people use React and how it is different from plain JavaScript
  • Setting up a project with Vite, and what the folder files do
  • Components and props: building a page from small reusable parts
  • State with useState and effects with useEffect, in plain language
  • Showing lists, forms and filters in React
  • Moving between pages with React Router
  • Connecting a React app to an API and styling it with CSS
ReactViteReact Routernpm

Outcome: Build a multi-page React app that gets data from an API and shows it cleanly.

Module 7Backend with Node.js and Express

Weeks 15-16
  • What a backend is and why a website needs one
  • Node.js basics: running JavaScript outside the browser
  • Express: creating routes for GET, POST, PUT and DELETE
  • Reading data sent from a form or a React page
  • Environment files for secret keys, and why they never go on GitHub
  • Testing every route in Postman
  • Sending errors in a clear way and allowing the front end to talk to the backend with CORS
Node.jsExpressPostmanNodemon

Outcome: Create your own small API with Node.js and Express and connect a React page to it.

Module 8PostgreSQL, Login and Deployment

Weeks 17-18
  • What a database is: tables, rows and columns, like a register for a coaching class
  • Basic SQL: select, insert, update, delete, where, order and join
  • Connecting Express to PostgreSQL with the pg package
  • Sign-up and login: storing passwords safely with bcrypt
  • Keeping people logged in with JSON Web Tokens (JWT)
  • Basic safety habits: checking input and not trusting what users send
  • Putting the front end, backend and database online with Vercel, Render and Neon
PostgreSQLpgAdminbcrypt and JWTRenderVercel

Outcome: Build a login-based app that saves data in a SQL database and run it live on the internet.

Module 9Capstone, Portfolio and Career Preparation

Weeks 19-20
  • Planning a capstone for a real or imagined client, such as a clinic booking site or a coaching class portal
  • Building and testing it with mentor reviews every few days
  • Cleaning the code, writing a clear README and recording a short demo
  • A simple portfolio website with all three projects and live links
  • Writing a one-page resume and a LinkedIn profile with your GitHub link
  • Mock interview covering HTML, CSS, JavaScript, React and basic backend questions
  • How to talk to a small business client: scope, time and what to say when you do not know
GitHubLinkedInVercelRender

Outcome: Show a live portfolio with three deployed projects and answer common beginner interview questions.

Frequently Asked Questions — Web Development

Is web development worth learning in 2026?
Yes, if you are ready to practise regularly. Shops, clinics, schools and startups still need websites and web apps, and someone has to build and maintain them. We cannot promise a job, but the skills are in steady demand, and the projects you build give you real work to show.
What is the fee for the Web Development course?
Fees are shared by our advisor on a call or on WhatsApp. EMI-style payment options are available on enquiry. Contact us with your background and we will explain the batch and the fee clearly.
Do I need any coding knowledge to join?
No. We start with how a website reaches your screen and write the first HTML page together. Every new idea comes with a small example from daily life. If you can use a laptop and are willing to practise, you can follow the course.
Is the course offline in Nagpur or online?
Both. You can attend offline at our Ramdaspeth centre in Nagpur, online through live Zoom classes, or in a hybrid way, with some days at the centre and some days from home. Batches are small, so your doubts get answered in class. Every student also gets one-on-one mentor sessions.
How is this different from learning from YouTube videos?
YouTube is useful for single topics, but it does not give you a clear order, a deadline or someone who checks your code. Here you learn in a fixed order, practise for 8 hours every week, and a mentor reads your code and tells you what to fix. You also end with three deployed projects instead of many half-finished ones.
Can a commerce, arts or non-IT student join?
Yes. The course is made for people who have never written code. A degree in IT is not required. You will need regular practice, and the first month may feel slow, but it is the base for everything after it.
How is this different from the MERN Stack course?
This is the base course. It teaches HTML, CSS, plain JavaScript, a first React project, a simple Node.js and Express backend, and a SQL database. The MERN Stack course is for people who want to go deeper into the MongoDB, Express, React and Node way of building bigger apps. Many students take this course first.
What does the course not cover?
It does not go deep into TypeScript, Next.js, WordPress or large cloud setups. It also does not cover mobile apps. The aim is to give you strong basics and a few finished projects, so that learning the next tool becomes easier.
Will I get a certificate?
Yes. After you complete the course and the capstone, you receive the Course Completion Certificate — Skilleze Technologies. Employers will look at your live projects and GitHub more than the certificate, so we spend time on those as well.
