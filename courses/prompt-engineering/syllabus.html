Module-by-Module Curriculum

Module 1:Clear Instructions and Examples

Week 1

Core Topics

  • What a prompt is, and why a vague prompt gives a vague answer
  • The four parts of a good prompt: task, context, audience and format
  • Rewriting weak prompts, using real tasks like a fee reminder for a coaching class
  • Putting examples inside the prompt: one example, two examples, and when more examples help (called few-shot prompting)
  • Saying what to avoid: length limits, words not to use, and the right tone
  • Prompts in English, Hindi and Marathi: what works and what goes wrong
  • Running the same prompt in ChatGPT, Gemini and Claude and comparing the answers

Tools & Tech

ChatGPTGoogle GeminiClaude

Learning Outcomes

  • Write a clear prompt with task, context, audience and format, and improve a weak prompt step by step.

Module 2:Role, Format and Step-by-Step Prompts

Week 2

Core Topics

  • Giving the AI a role, like a tutor, a shop assistant or a proofreader, and when a role helps
  • Controlling the format: tables, bullet lists, word limits, fixed headings and copy-ready WhatsApp messages
  • Asking for output you can paste straight into Google Sheets or Excel
  • Step-by-step reasoning prompts: asking the AI to work through a problem like a GST total or a fee split
  • Breaking a big task into small prompts that run one after another (called prompt chaining)
  • Custom instructions, so you do not type the same rules in every chat
  • Common mistakes: too many instructions in one prompt, and instructions that clash with each other

Tools & Tech

ChatGPTClaudeGoogle AI StudioGoogle Sheets

Learning Outcomes

  • Control the role, format and thinking steps of an answer, and break a bigger task into a short chain of prompts.

Module 3:Checking Answers and Building Prompt Templates

Week 3

Core Topics

  • Why AI gives wrong answers with full confidence (called hallucination)
  • Checking facts, numbers, dates and names, asking for sources, and then opening those sources
  • Asking the AI to review its own answer, and why that alone is not enough
  • Testing one prompt on 5 to 10 different inputs before you trust it
  • A simple look at hidden instructions in pasted text (called prompt injection) and how to stay careful
  • A template is a prompt with blanks: writing one with fields like product, audience and tone
  • Keeping customer, student and patient data out of your prompts

Tools & Tech

ChatGPTGoogle GeminiPerplexityGoogle Docs

Learning Outcomes

  • Catch common wrong answers, test a prompt on several inputs, and turn a working prompt into a reusable template.

Module 4:Prompt Library, Final Project and Career Preparation

Week 4

Core Topics

  • Marketing templates: Instagram captions, product descriptions and WhatsApp broadcast messages
  • Support templates: reply drafts for complaints, delays and refund requests in a polite, fixed tone
  • Coding help templates: explaining an error message, explaining code line by line, and running the result yourself to check it
  • Study templates: summaries, practice questions and simple explanations of hard topics
  • Organising your personal prompt library in Notion or Google Docs, with the use, an example and the date tested
  • Final project review with a 1-on-1 mentor session
  • Resume line, LinkedIn post and a short mock interview or client task, including how to describe a one-month course honestly

Tools & Tech

Learning Outcomes

  • Present a tested prompt library for marketing, support, coding help and study, and explain clearly what you can and cannot do with it.
