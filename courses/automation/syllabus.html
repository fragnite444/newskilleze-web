Module-by-Module Curriculum

Module 1:Automation Fundamentals & n8n

Week 1

Core Topics

  • What is workflow automation: triggers, actions, conditions, and data transformation
  • n8n interface: workflows, nodes, connections, and credentials management
  • Core n8n nodes: HTTP Request, IF, Set, Merge, Function, Code, Loop
  • Trigger types: webhook trigger, schedule (cron), on-event triggers
  • Building your first workflow: form submission → Google Sheets → Slack notification
  • Data mapping: JSONPath expressions, $json, $node references in n8n
  • Error handling: Retry on fail, Error Trigger, and workflow error branches

Tools & Tech

n8n (self-hosted / cloud)Docker (n8n setup)Webhook.site

Learning Outcomes

  • Build a multi-step n8n workflow triggered by a webhook that reads data, applies conditional logic, writes to Google Sheets, and sends a formatted Slack message.

Module 2:Make (Integromat) — Advanced Workflow Design

Week 2

Core Topics

  • Make interface: scenarios, modules, routes, and filters
  • Scenario scheduling and trigger types: instant webhooks vs scheduled runs
  • Routers and filters: conditional branching in Make scenarios
  • Data stores in Make: key-value storage for cross-scenario memory
  • Aggregators and iterators: processing arrays and lists in Make
  • Error handlers: ignore, resume, rollback, and commit patterns
  • Make vs n8n: when to choose which platform for a given business problem

Tools & Tech

Make.comWebhooksJSON / XML parsingRegex in Make

Learning Outcomes

  • Design and run a Make scenario with routers, filters, data stores, and aggregators — handling an array of records conditionally and logging errors robustly.

Module 3:Zapier, API Integration & Webhooks

Week 3

Core Topics

  • Zapier fundamentals: Zaps, triggers, actions, filters, and Paths (branching)
  • Multi-step Zaps: chaining 5+ actions for complex business processes
  • Zapier Formatter: date/time, text, number transformations built-in
  • API integration basics: REST, HTTP methods, authentication (API key, OAuth2, Bearer)
  • Using Zapier's Webhooks by Zapier for custom API triggers and actions
  • Connecting no-code tools: Typeform → HubSpot → Slack → Gmail automation
  • Choosing between Zapier, Make, and n8n based on budget, scale, and tech comfort

Tools & Tech

Week 4
